# 設計(アーキテクチャ)

## 全体の流れ

「聞く → 訳す → 話す」の3工程をベルトコンベアのようにつなぎます。

```
  🎤 マイク
     │ 音声
     ▼
 ┌──────────────┐  Transcript(文字+言語)
 │ ① 音声認識     │ ─────────────┐
 └──────────────┘              ▼
                         ┌──────────────┐
                         │ 言語判定       │ 日本語? ベトナム語?
                         └──────────────┘
                                │
                                ▼
                         ┌──────────────┐
                         │ ② 翻訳         │ 長文は文ごとに分けて訳す
                         └──────────────┘
                                │ 訳文
                                ▼
                         ┌──────────────┐
                         │ ③ 音声合成     │ 日→越は声A、越→日は声B
                         └──────────────┘
                                │
                                ▼
                              🔊 スピーカー

 ④ 評価:各工程の結果(TranslationEvent)を記録し、正解データと比べて点数化
```

`TranslatorCore` にある4つのプロトコル(`SpeechRecognizing` / `Translating` / `SpeechSynthesizing` / `LanguageDetecting`)が **コンセントの形** です。
形さえ合っていれば、差し込むプラグ(Apple 純正・Whisper・Mac 経由など)を自由に入れ替えられます。
だから4つのワークストリームは互いを待たずに並行して開発できます。

## 使う無料技術(初期案)

| 工程 | iPhone 単体(基本) | Mac 連携モード(候補) |
|---|---|---|
| ① 音声認識 | Speech フレームワーク(iOS 26 以降が対象なので新しい `SpeechAnalyzer` が第一候補、`SFSpeechRecognizer` は比較用) | WhisperKit(オープンソース・無料)で高精度認識 |
| ② 翻訳 | Translation フレームワーク(端末内・無料、初回に言語データをダウンロード) | Mac 側の Translation フレームワーク、または無料のローカル翻訳モデル |
| ③ 音声合成 | `AVSpeechSynthesizer`(Premium/Enhanced 音声を無料で追加可能) | Mac の高品質音声で合成して音声ファイルを返す |
| 言語判定 | 文字種判定 + `NLLanguageRecognizer` | 同左、または Whisper の言語判定 |

> 注意(推測を含む):ベトナム語の音声認識が端末内だけで動くかは iOS の版によって異なります。対応していない場合は Apple のサーバー認識(無料だが通信あり・回数制限あり)に自動で切り替わります。ワークストリーム①の最初の調査項目です。

## Mac 連携モード

家や職場で Mac が近くにあるときは、重い処理を Mac に任せて精度と速さを上げます。

```
 ┌─────────── iPhone ───────────┐          ┌──────────── Mac ────────────┐
 │ 🎤 マイク                      │  音声    │                              │
 │   └─ audioChunk ────────────────┼────────▶│ ① 認識(WhisperKit など)      │
 │                                │          │ ② 翻訳                       │
 │ 画面表示 ◀── transcript ────────┼─────────│                              │
 │ 🔊 読み上げ ◀── translation ────┼─────────│ ③ 合成(任意:synthesizedAudio)│
 └────────────────────────────────┘  同じWi-Fi └──────────────────────────────┘
          Bonjour(_jvtranslate._tcp)で自動発見、JSON Lines で送受信
```

- **見つけ方**:Bonjour(同じ Wi-Fi 内の機器を名前で自動で探す仕組み。プリンタが自動で見つかるのと同じ)。
- **送り方**:`CompanionMessage` を JSON にして1行ずつ送る(`CompanionCodec`)。
- **iPhone 側のつなぎ方**:`RemoteTranslator` は普通の `Translating` と同じ形なので、パイプラインは何も変えずに「中身だけ Mac 行き」に差し替えられます。
- **切れたら**:接続が切れたら自動で iPhone 単体モードに戻る(今後実装)。

例えるなら、iPhone は「通訳者の耳と口」、Mac は「隣に座っている物知りの助手」です。助手がいれば頼り、いなければ自分でこなします。

## 今後の設計課題

1. 自動言語判定:日本語とベトナム語の認識器を同時に走らせ、確信度と言語判定で片方を採用する。
2. 文の区切り:話し終わり(無音)を検出して、文ごとに確定させる(今は認識タスクの終わりまで待つ)。
3. 自分の読み上げ音声をマイクが拾わないようにする(読み上げ中は認識を止める or エコーキャンセル)。
